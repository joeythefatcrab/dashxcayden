# Sprint — April 2026

## Summary
Monthly report submission flow, admin notifications, nav overhaul, file attachments, and APS form alignment.

---

## Shipped

### Navigation
- Replaced flat admin nav with grouped dropdowns: **People** (Manage Parents, Assign Students, Impersonate User), **Content** (Curricula, Curriculum Access, Programs), **Track** (Reports, Activities, Messages)
- Right-side user menu with avatar initials, role badge, Settings, Sign Out
- Nav badges: all roles poll `/api/revision-count` every 30s
  - Student/Parent: red badge on their primary link when revision requests pending
  - Admin: Track badge combines `pendingReports + revisionCount`

### Superadmin
- Inline name editing on users page (`components/superadmin/EditUserName.tsx`)
- API: `PATCH /api/superadmin/update-user` — updates name in DB
- Session refresh via `update({ name })` after save so nav updates immediately without re-login
- JWT callback handles `trigger === "update"` to write new name into token

### Monthly Report — Submit Flow
- Parent-facing big submit button at bottom of report with confirmation dialog (student name + month/year)
- Post-submit: green confirmation card with timestamp + resubmit option
- `POST /api/parent/submit-report` — marks `submittedAt`, sends email to opted-in admins
- Impersonation-safe: admins impersonating parents can submit on their behalf
- Email uses `@react-email/components` via Resend; attendance counts computed from `dailyAttendance` records (not raw JSON field)
- PDF generated on-demand at `GET /api/reports/[reportId]/pdf` using `@sparticuz/chromium` + `puppeteer-core`
- Email includes **Download PDF Report** button linking to the route instead of attachment (avoids DMARC stripping)
- `NEXTAUTH_URL` normalized to include `https://` if missing

### Admin Notifications
- Floating amber banner (`components/admin/ReportSubmissionBanner.tsx`) appears when unreviewed submitted reports exist
- Polls `/api/admin/pending-reports` every 30s
- Dismiss marks all as reviewed via `PATCH /api/admin/mark-report-reviewed`
- Admin email opt-in: `notifyOnReportSubmission` boolean on `User` (set in admin settings)
- Both routes use raw SQL with try-catch to gracefully handle migration not yet applied

### Essay Revision Requests
- `DELETE /api/admin/programs/[id]/submissions` — cancels a revision request (sets status back to `SUBMITTED`, clears `adminNote`)
- Cancel Revision button in `ChecklistReviewPanel` for PENDING items with adminNote
- `/api/revision-count` — unified count endpoint:
  - STUDENT: counts their own PENDING essays with adminNote
  - PARENT: counts across all their students
  - ADMIN/SUPERADMIN: counts SUBMITTED essays awaiting review

### PDF Report
- `lib/build-report-html.ts` — pure TS HTML string generator (avoids `react-dom/server` in API routes)
- `lib/generate-pdf.ts` — puppeteer wrapper, returns `Buffer`
- Report structure matches APS paper form exactly:
  - Title: **Monthly Attendance**
  - Section 1: Monthly Attendance calendar (Mark: P/A/S/V)
  - Eval questions (no section header): Name, Successes, Program Targets, Anything to share
  - Monthly Study Progress table (7 APS subjects, Description, Time)
  - Attachments (if any)
  - Footer

## Database Migrations (run in Neon)

```sql
-- 1. Report submission + admin email opt-in
ALTER TABLE "MonthlyReport" ADD COLUMN IF NOT EXISTS "submittedAt" TIMESTAMP(3);
ALTER TABLE "User" ADD COLUMN IF NOT EXISTS "notifyOnReportSubmission" BOOLEAN NOT NULL DEFAULT false;

-- 2. Admin reviewed flag
ALTER TABLE "MonthlyReport" ADD COLUMN IF NOT EXISTS "adminReviewed" BOOLEAN NOT NULL DEFAULT false;

-- 3. Report attachments table
CREATE TABLE IF NOT EXISTS "ReportAttachment" (
  "id"        TEXT NOT NULL,
  "reportId"  TEXT NOT NULL,
  "url"       TEXT NOT NULL,
  "name"      TEXT NOT NULL,
  "size"      INTEGER,
  "mimeType"  TEXT,
  "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT "ReportAttachment_pkey" PRIMARY KEY ("id"),
  CONSTRAINT "ReportAttachment_reportId_fkey" FOREIGN KEY ("reportId") REFERENCES "MonthlyReport"("id") ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS "ReportAttachment_reportId_idx" ON "ReportAttachment"("reportId");
```
